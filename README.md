# 制造业算法学院

从基础到高深的制造业算法互动课程网站，共 11 节课，分基础、进阶、高级、展望四个阶段，覆盖质量、设备、工艺、能源、计划、综合六大板块。

每节课包含：生活类比与通俗讲解、交互模拟、可下载的模拟数据 CSV、带 KPI 的工厂落地案例、2 道带解析的小测，支持进度标记与按板块/阶段筛选。

## 课程一览

- 基础篇：排序查找、SPC、贪心
- 进阶篇：回归、决策树、K-Means、动态规划
- 高级篇：遗传算法、神经网络、强化学习
- 展望篇：工业 AI 的下半场（受控闭环控制、机理+数据混合建模、小样本与数据治理、全价值链多智能体协同、可靠性与持续运维、规模化复制与 ROI）

## 打开方式

直接用浏览器打开 `index.html` 即可学习；也可以在仓库 Settings → Pages 中选择 main 分支发布为在线网站。

## 说明

其中企业与数据均为课堂模拟，非真实工厂数据。
