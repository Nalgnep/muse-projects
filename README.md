# 制造业算法学院

面向制造现场的中文学习站，五个页面组成一条路径：先建立算法直觉，再按任务书做项目，立项前把账算清，上线前排雷，最后把设备接到看板上。

全部是静态 HTML，可直接用浏览器打开，也可放到 GitHub Pages。企业、金额和传感器数据都是课堂模拟，不是真实工厂数据，也不是报价或收益承诺。

## 五站

| 顺序 | 页面 | 你在这里做什么 |
| --- | --- | --- |
| 1 | [算法课程](index.html) | 11 节互动课。SPC 课含个体值图，以及用 A2/D3/D4 计算的均值-极差图 |
| 2 | [实战项目](industrial-ai-projects/) | 8 个端到端项目。预测维护的交互实验里有轴承包络谱（`#p2-sim`） |
| 3 | [ROI 测算](industrial-ai-roi-calculator/) | 投入、良率、人力、停机，算出回本周期、现金流和立项摘要 |
| 4 | [避坑手册](industrial-ai-pitfalls/) | 数据、验收、运维 10 个翻车点，外加风险自测和上线红线 |
| 5 | [IoT 看板](industrial-ai-iot-dashboard/) | MQTT、ThingsBoard、规则告警和 AI 摘要的可运行讲解 |

页顶导航在五个页面之间切换。课程支持搜索、分享链接（如 `index.html#spc`）和本机进度；项目可以用 `industrial-ai-projects/#p2` 打开，`#p2-sim` 直接进入交互实验。

## 打开方式

在仓库根目录起一个静态服务再访问，避免用 `file://` 时部分浏览器限制本地存储：

```bash
python3 -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/`。

GitHub Pages 请发布 **main** 以外你合并后的分支，或在仓库 Settings → Pages 选择发布分支的根目录 `/`。这是项目站点，页面之间使用相对路径，不依赖域名。自定义 404 在 `404.html`。

## 口径说明

- SPC 判异按 GB/T 4091 来写：1 点越界、连续 9 点在中心线同一侧、连续 6 点单调。个体值图只用于建立直觉。
- ROI 默认仍是原来的粗算：年产值 × 提升百分点 ÷ 100，折现率为 0。需要时再切换「按当前良率精算」，或把折现率调到 8% 看 5 年 NPV。
- 预测性维护的第一周基线用振动速度有效值（ISO 10816）。轴承早期损伤还要看加速度包络和峭度。
- IoT 页里的 8080 / 1883 只建议调试期临时放开，上线后改走 443 和 8883/TLS。
