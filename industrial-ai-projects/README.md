# 工业 AI 实战项目

制造业算法学院的项目制续篇：8 个端到端工业 AI 落地项目，覆盖质量、设备、工艺、能源、计划、综合六大板块。

项目一览：视觉质检、预测性维护、工艺参数优化、峰谷负荷调度、智能排产、焊接根因分析、需求预测与库存、数字孪生闭环。

每个项目包含：任务书（痛点、目标、验收 KPI、立项三问）、6 步实施路线、可拖动的交互实验、可下载的 120 行模拟数据 CSV、2 道带解析的小测验；另有按板块/难度筛选、90 天落地路线、技术栈速查。

## 打开方式

直接用浏览器打开 `index.html` 即可；本仓库已开通 GitHub Pages，在线地址见仓库主页。

## 说明

其中企业与数据均为课堂模拟，非真实工厂数据。
