# IoT 看板实战

把阿里云 ECS/VPS、ThingsBoard、MQTT 与 DeepSeek 串成一条完整链路，按 9 个目录分类组织：顶部是可交互的实时看板仿真（6 台模拟设备、温度曲线、KPI、告警事件流），可注入异常、暂停/恢复、下载模拟 CSV、一键生成 AI 摘要；正文含架构与选型对照、八步手把手实操（Docker Compose、Python MQTT 模拟器、规则链脚本、DeepSeek 摘要服务、Nginx 上线，全部代码可复制）、MQTT 报文实验、自定义规则告警实验、AI 提示词拆解、上线清单与课堂估算成本、排障手册和小测。

## 打开方式

直接用浏览器打开 `index.html` 即可；本仓库已开通 GitHub Pages，在线地址见仓库主页。

## 说明

其中设备、数据与成本均为课堂模拟，非真实工厂数据。
